# groundcover_slides

Presentation decks for groundcover talks, workshops, and webinars. Each deck lives
in its own folder and is self-contained — build and run instructions are in that
folder's own README.

## Decks

| Slide deck | Description |
|---|---|
| [`eBPFvOTel/`](./eBPFvOTel) | **eBPF + OTel: Two Layers, One Observability Strategy** — Slidev deck for the live workshop with David Flanagan (CoreWeave / Rawkode Academy) and Anais Dotis-Georgiou (groundcover), September 2, 2026. Six slides covering eBPF vs. OTel tradeoffs, the BYOC architecture, and three demo examples. Uses the groundcover brand template. |

## Running a deck

```bash
cd <deck-folder>
npm install
npm run dev      # http://localhost:3030
```
